# SENTRY 前端视觉规范

更新日期：2026-09-08。适用于当前 Web 面板，覆盖历史《前端优化方案》中与视觉、布局相关的旧约定；历史功能约束与数据口径继续保留。

## 设计方向

采用“深海墨色 · 薄荷青”的专业观测控制台风格。页面以导航、概览、证据、明细四个层级组织信息，使用稳定的留白与细边框建立结构。取消全屏网格、噪点、暗角、卡片编号和标题侧色条，避免装饰与数据竞争注意力。

本次仅更新 `internal/web/static/index.html`、`internal/web/static/app.js` 和前端相关文档、验证材料。保持原生 JavaScript、ECharts、零 CDN 和 Go 内嵌资源方式，无新增前端依赖。

## 页面组织

| 页面 | 布局与阅读顺序 | 原有操作 |
| :--- | :--- | :--- |
| 安全总览 | 页面标题 → 五项 KPI → 风险评估与攻击趋势 → 来源与端口榜 → 资源、通道健康、事件流 | 时间范围切换、端口联动、来源画像、复制 IP、折叠与展开 |
| 连接观测 | 页面标题 → 当前连接快照 → 最近连接事件 | 明细预览、排序、源 IP 过滤、画像与 CSV 导出 |
| 攻击分析 | 页面标题 → 端口 / 来源排行、时间线 / 封禁名单 → 全球分布 → 蜜罐、凭据字典、SSH、威胁明细 | 图表过滤、国家过滤、协议过滤、密码显隐、各类明细导出 |
| 数据导出 | 左侧导出表单，右侧用途与字段说明 | 四档预设、自定义时间段、校验、下载与结果反馈 |

桌面导航固定在左侧，主内容有独立页面标题；小屏使用顶部横向导航。通知按钮保留权限状态反馈。全局时间范围、过滤提示、连接状态和数据保留期仍在顶部可见。

| 交互强调 | `--accent`、`--accent-strong` | `#79DCC5` |

- 中文正文优先 Microsoft YaHei UI / PingFang SC；标题与 KPI 数字优先 Bahnschrift；IP、时间、表格数字采用 Cascadia Code / Consolas 等宽回退栈。字体均来自本机，平台差异属于正常回退。
- 页面标题 28px，卡片标题 14px，正文与表格约 12～13px，辅助说明 10～11px，桌面 KPI 数字 32px。
- 圆角采用 14px 卡片、7px 控件、4px 微件；常用卡片间距 18px，主内容左右留白 32px。
- ECharts 主色、文字、提示浮层和边框通过读取 CSS 变量统一。资源曲线保留区分序列的配色，风险语义色不改变。

## 图表与数据语义

风险仪表使用灰色轨道与按原阈值着色的进度弧，中心显示分数；去除指针。评分函数、权重、阈值和累计范围保持不变。说明继续明确：仅本机攻击行为与资源维度，不含漏洞、CVSS 或威胁情报，跨时间范围不可直接比较。“SSH 失败次数”与实际计数相匹配。

攻击活动保持入站探测、拦截、SSH 失败三通道与双 Y 轴。7d / 30d 仍支持原有缩放。榜单比例条设置为块级元素，使其宽度与真实比例一致。全球地图依然仅统计 SSH 失败来源。

空数据与请求失败沿用独立状态。演示与验证数据不进入生产资源，不能作为真实攻击量或性能指标。

## 响应式与交互

| 宽度 | 布局规则 |
| :--- | :--- |
| 大于 1200px | 208px 侧栏、五列 KPI、风险 / 趋势非等宽双列、四列资源图 |
| 901～1200px | 176px 侧栏、KPI 两项 + 三项、资源双列 |
| 641～900px | 顶部横向导航、风险 / 趋势双列、导出单列 |
| 不超过 640px | 卡片单列、KPI 双列且最后一项通栏、时间控件换行、导出时间输入纵向排列 |

表格保留容器内横向滚动，极窄屏导航允许内部横向滚动，整页不横向滚动。四页在 320、360、375、390、640、768、900、1024、1440、1920px 进行浏览器检查。

全局过滤提示使用原生按钮，支持键盘 Enter 清除；全局和导出时间按钮同步 `aria-pressed`，自定义导出模式清除所有预设选中态，当前导航同步 `aria-current`。页签切换聚焦该页标题并回到顶部；提供“跳转到主内容”链接。采样说明支持键盘聚焦查看。减少动态效果偏好下关闭 CSS 动效与本次涉及的图表过渡。

## 维护与验证

样式继续位于 `index.html` 内，兼容后端现有 `style-src 'unsafe-inline'` 策略；不要直接改为外链 CSS，除非另行授权并调整、验证 CSP。本次不改 CSP、API、数据库、采集服务、配置或部署文件。

复跑入口为 [frontend_visual_check.py](verification/tools/frontend_visual_check.py)，说明见 [验证工具](verification/tools/README.md)。验证结果与局限见 [前端视觉升级验证记录](verification/FE-20260908_视觉升级验证.md)。

前端资源由 Go 编译时内嵌，现有运行中的旧二进制不会自动读取源码变更。发布新界面需要按现有流程重新构建并替换二进制；本次不执行部署。
