## 2. 关键设计决策

1. **独立只读连接**（auditor 坑点落地）：api.Server 以 `mode=ro` 打开独立连接（MaxOpenConns(4)），与写线程（MaxOpenConns(1)）完全隔离；TestReadOnlyConnection 验证 WAL 多读者并发读写无冲突。
2. **WS 帧实现选择**（记录偏离）：方案 3.7"从采集 channel 复制订阅"改为**只读连接查询 + 定时推送**（1s/5s/30s 帧）——避免 fanout 层侵入主采集链路（背压传导风险），面板数据一致性由"推送=查询快照"保证（延迟 ≤ 帧周期）；效果等价（conn_stats 1s 帧实测 35/35s）。
3. **前端零 CDN**（方案 3.8）：ECharts 5.5.1 本地文件（1.03MB）embed 打包，VPS 无外网可用。
4. **active_conns 口径**（方案 3.7 注释）：ss 快照 atomic.Value（main 注入 snapshotFn），非 SQL 窗口差值；实测 summary active_conns 与 snapshot 一致。
5. **DPT 口径**：攻击端口 TOP 仅防火墙 DPT 字段（summary/top_ports 均 action='drop' + dst_port 聚合，方案 3.4 强制）。
6. **磁盘水位完整形态**：diskmon 协程（5 分钟周期）三级告警 + 限频 + 回落事件；与 archive.ShouldSkipArchive（critical 90% 跳过）阈值共用配置（disk.critical_percent）。

- **conn_stats 帧语义披露（DEV-007 R-07）**：conn_stats 的 new/destroy 计数采用进程启动以来 id 游标增量（W-01 双游标）——**agent 重启后首帧 new/destroy 为历史全量计数**（含重启前的全部 NEW/DESTROY 事件），随后为增量；前端当前仅消费 active 字段不受影响，未来消费 new/destroy 的消费者须知悉首帧语义。

## 4. 环境限制与未验证项

- **浏览器级渲染截图未做**：Windows→WSL 网络隔离（镜像网络模式 8080 不互通），浏览器无法访问 WSL 内 agent；以"数据断言 + 静态资源 + WS 帧"组合满足验收 3（任务书允许"DOM/数据断言"口径）；tester 回归可在 VPS 或 WSL 内 headless 浏览器补截图
