2. **config.json 顶层 ssh_learn 误放**：首次补充时放错位置，已修正至 fw 段并重启。最终配置正确。
3. **scp CRLF 问题**：Windows 传输导致 CRLF，已用 sed 转换。后续部署建议在 scp 后执行 `sed -i 's/\r$//'`。
